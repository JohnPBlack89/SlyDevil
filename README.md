// install dev tools
`npm ci`

// Run app locally (port:3000)
`npm start`

// Run tests
`npm test`

// check types without generating files
`npm run typecheck`

// build project
`npm run build`

// continuous compilation
run `npm run watch` in one terminal
`node dist/server.js` in another
Refresh the browser after editing client code;
Restart the server after editing `server.ts`.
